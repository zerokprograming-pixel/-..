# مساعد QUREO

صفحة ويب عربية بسيطة ومتوافقة مع الهاتف لمساعدة الطالب على فهم تمارين البرمجة في QUREO.

## ما الذي تفعله؟
- تستقبل نص السؤال ومحاولة الكود.
- تجهّز مطالبة تعليمية وتنسخها إلى الحافظة.
- تفتح ChatGPT لتلصق المطالبة وتحصل على شرح وتلميحات.

## ما الذي لا تفعله؟
- لا تسجّل الدخول إلى QUREO.
- لا تطلب اسم المستخدم أو كلمة المرور أو رمز QR.
- لا تنفّذ الاختبارات أو ترسل الإجابات أو تتنقل تلقائياً بين الفصول.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع الملفات `index.html` و`style.css` و`app.js`.
3. افتح **Settings → Pages**.
4. اختر **Deploy from a branch** ثم `main` والمجلد `/ (root)`.
5. احفظ وانتظر ظهور رابط GitHub Pages.

## التشغيل محلياً
افتح `index.html` في متصفح حديث. قد تتطلب ميزة نسخ النص HTTPS أو localhost؛ إذا لم تعمل، ستظهر خانة بديلة للنسخ اليدوي.
